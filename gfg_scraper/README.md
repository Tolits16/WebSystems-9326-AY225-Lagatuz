# GeeksforGeeks Academic Scraper
### Web Technology Project

A full-stack web application that scrapes 12 Web Technology articles
from GeeksforGeeks and generates a professional academic PDF.

---

## How to Run

```bash
# 1. Install dependencies
pip install flask requests beautifulsoup4 reportlab

# 2. Start the server
python app.py

# 3. Open dashboard
http://localhost:5050
```

## Step-by-Step Usage

1. Click **Run Scraper** — fetches all 12 GFG articles live
2. Preview all scraped data in the dashboard cards
3. Click **Generate PDF** — builds the academic PDF
4. Click **Download** to save the PDF

## What Gets Scraped (per article)

| Field | Source in HTML |
|-------|---------------|
| Topic Title | `<h1>` tag |
| Difficulty Level | Badge elements or page text regex |
| Key Technical Concepts | First paragraph in article body |
| Code Snippet | `<pre>` blocks with newlines |
| Complexity Analysis | Paragraphs mentioning O() notation |
| References | Links after "References" section heading |

## Project Structure

```
app.py              ← All logic: scraper + PDF generator + Flask API
data/
  scraped_data.json ← Saved after scraping (offline mode)
  scraped_data.csv  ← Same data in spreadsheet format
pdfs/               ← Generated PDF modules saved here
templates/
  index.html        ← Web dashboard UI
requirements.txt
```

## Compliance

- **Zero Hardcoding**: Only URLs in GFG_TOPICS; all content fetched live
- **Offline Mode**: Load Cached Data works without internet after one scrape
- **robots.txt**: 2-second delay between each request
